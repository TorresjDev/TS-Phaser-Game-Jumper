# Code of Conduct

## Our pledge

We want this project to be a welcoming, respectful community for everyone.

## Our standards

Examples of positive behavior:

- Being respectful and constructive in feedback
- Assuming good intent and helping others learn
- Focusing discussions on ideas, not people

Examples of unacceptable behavior:

- Harassment, discrimination, or hate speech
- Personal attacks, insults, or trolling
- Publishing private information without permission

## Scope

This code of conduct applies to repository discussions, issues, pull requests, and related community spaces.

## Enforcement

Project maintainers may remove or reject content that violates this code and may limit participation for repeated or severe violations.

## Reporting

Report incidents through GitHub issues labeled appropriately, or directly to the maintainer via GitHub profile contact options.
