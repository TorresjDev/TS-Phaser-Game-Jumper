# Security Policy

## Supported versions

Security fixes are prioritized for the latest version on the `main` branch.

## Reporting a vulnerability

Please do not open a public issue for security vulnerabilities.

Instead:

1. Open a private security advisory on GitHub if available for this repository.
2. Or contact the maintainer directly through GitHub profile contact options.
3. Include clear reproduction steps and impact details.

You can expect acknowledgment as soon as possible, followed by a triage update and remediation plan.
